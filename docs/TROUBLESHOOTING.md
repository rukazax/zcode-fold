# Если нет связи 🔌

Короткий разбор: что проверить, если ZCode Fold пишет «офлайн», «мост не отвечает»
или не видит задачи. Все команды — для ПК, если не сказано иное.

> 💡 Главное правило ZCode 3.17: **QR-ссылка — это только адрес компьютера**.
> Для relay нужен токен аккаунта Z.ai. Приложение получает его мостом с ПК,
> а не из самого QR. Поэтому «отсканировал QR, а связи нет» — это почти всегда
> отсутствующий токен.

## Быстрая диагностика 🩺

| Симптом | Вероятная причина | Что делать |
|---|---|---|
| После QR — «офлайн», в сайдбаре янтарный баннер про токен | Нет JWT аккаунта Z.ai | Запустить `node tools/bridge.mjs`, забрать токен по QR/URL → «Подключить / войти» |
| «Мост не отвечает», таймаут 12 с | Мост не запущен, порт занят или брандмауэр | Проверить `/health`, разрешить Node в частной сети |
| Мост запущен, но телефон не открывает файлы | Телефон и ПК в разных сетях / VPN перехватывает LAN | Одна Wi-Fi-сеть, split tunneling или `adb reverse` |
| `adb connect` таймаут, `ping` 100% потерь | VPN-маршрут забирает подсеть телефона | Точечный маршрут через шлюз Wi-Fi (ниже) |
| Связь есть, но «Пока нет задач» | В ZCode не открыт проект/workspace | Открыть проект на ПК, потянуть список вниз |
| Через время снова «офлайн» | Терминальный токен живёт ~60 с, JWT истёк | Переподключиться; при ошибке — обновить токен мостом |

## 1. Нет токена аккаунта 🔑

1. На ПК открой ZCode → **«Мобильное удалённое управление»**.
2. Запусти мост:

   ```bash
   cd tools
   npm install        # один раз
   node bridge.mjs
   ```

3. Скрипт напечатает `URL` и сохранит `bridge-qr.png`.
4. В приложении: **«Подключить / войти»** → вставь URL моста или отсканируй QR.
5. Приложение само заберёт JWT и подключится — перезапуск не нужен.

> ⚠️ Мост одноразовый: после выдачи токена он закрывается. Для файлов ПК
> используется отдельный долгоживущий мост на `:8940`, его приложение
> запускает само.

## 2. Мост не отвечает 📡

Проверь здоровье моста с ПК:

```bash
curl -H "Authorization: Bearer $(cat tools/bridge-fs.token)" \
  http://127.0.0.1:8940/health
```

Ожидаемый ответ:

```json
{"ok":true,"root":"C:/","name":"DESKTOP-XXXX"}
```

Если пусто:

```bash
# Windows: кто слушает порт
netstat -ano | findstr :8940
```

- Порт занят старым процессом → заверши его и нажми «Настроить ПК удалённо» ещё раз.
- Windows Firewall → разреши Node.js в **частных** сетях.
- Телефон в гостевой сети → подключи к основной, где стоит ПК.

## 3. ADB по Wi-Fi не видит телефон 📶

Сначала проверь сеть, а не пары:

```bash
ping 192.168.1.133
route print | findstr 192.168.1.0
```

Если `ping` не проходит, а телефон и ПК в одной подсети — почти наверняка
VPN (AmneziaVPN/WireGuard) забирает маршрут. Варианты:

- выключить VPN на минуту;
- добавить `192.168.1.0/24` в split tunneling;
- точечный маршрут только до телефона (PowerShell от администратора):

  ```powershell
  route add 192.168.1.133 mask 255.255.255.255 192.168.1.1 if 15 metric 1
  ```

Проверка, какой интерфейс реально выбран:

```powershell
Find-NetRoute -RemoteIPAddress 192.168.1.133
```

Должен быть `Беспроводная сеть`, а не `AmneziaVPN`.

## 4. Связь есть, задач нет 🗂

- На ПК должен быть **открыт проект** (workspace), а не пустой экран.
- Потяни список задач вниз — сработает refresh.
- Проверь, что сессии не в архиве: «Задачи» показывают активные.
- Если открыт только draft-workspace, задачи проекта появятся после первого
  сообщения или после открытия реального проекта.

## 5. Токен истёк 🔄

Терминальный токен живёт около минуты — это нормально, приложение чеканит
новый на каждый реконнект. Если истёк **JWT аккаунта**, приложение покажет
«Сессия Z.ai устарела». Тогда снова запусти `node tools/bridge.mjs` и обнови
токен. Логин в WebView — запасной путь (Google блокирует встроенные браузеры).

## Что прислать, если не помогло 📸

1. Скриншот экрана приложения (баннер/ошибка).
2. Вывод `node tools/bridge.mjs` с ПК (URL можно, токен — **не** присылай).
3. `ping <IP телефона>` и `Find-NetRoute -RemoteIPAddress <IP>`.
4. Версию ZCode на ПК и версию приложения из «Настроек».

> 🔒 Ссылка `/remote/v4?sid=…` и токен моста дают доступ к твоим сессиям.
> Не публикуй их и не пересылай скриншоты QR.
